# Catalog สินค้า (MVP ยังไม่ใช้ Affiliate Open API)

`products.csv` = ชุดสินค้าตั้งต้นสำหรับ sample use case (รูปห้องจริง 20 รูป: ห้องนอน / นั่งเล่น / คอนโด / ห้องโล่ง / ห้องรก)
50 รายการ ครอบ slot ที่โผล่ซ้ำบ่อยเวลาแต่งห้องใหม่ ไม่ได้ผูกกับสินค้าชิ้นใดชิ้นหนึ่งบน Shopee

## คอลัมน์

| คอลัมน์ | ความหมาย |
|---|---|
| `room_type` | bedroom / living / condo / empty / cluttered ตรงกับประเภทรูปห้องในชุดทดสอบ |
| `slot` | ช่องของในห้อง (lighting, rug, curtain, sofa, …) ใช้ map กับ item ที่ AI แตกออกมาจากรูป gen |
| `item_th` | ชื่อที่โชว์ในแอป |
| `keyword_th` / `keyword_en` | คำค้นจริงที่เอาไปยิง Shopee คำไทยคือคำหลัก อังกฤษไว้ให้ prompt ใช้ |
| `styles` | สไตล์ที่ของชิ้นนี้เข้ากัน (minimal, muji, japandi, scandi, loft, luxe, boho) คั่นด้วย `\|` |
| `price_min` / `price_max` | ช่วงราคาประมาณ (บาท) ไว้คัดของให้เข้างบ **ไม่ใช่ราคาจริง อย่าโชว์เป็นราคาสินค้า** |
| `priority` | 1 = ชิ้นที่เปลี่ยนหน้าตาห้องมากสุด ควรเสนอก่อน, 3 = ของเสริม |
| `deeplink` | ว่างไว้ก่อน เติมตอนได้ affiliate link (ดูข้างล่าง) |
| `note` | ข้อควรระวังตอนแนะนำ |
| `check_status` | ผลค้นจริงบน Shopee 18 พ.ย. 2026: ok / fixed (แก้คำแล้ว) / broad (คำขยายถูกเมิน) / weak (ผลปนเยอะ) / dup (ผลซ้ำแถวอื่น) |
| `check_note` | เจออะไรตอนค้น |

## ตอนนี้ (ยังไม่มี affiliate link)

ปุ่มในแอปยิงไปที่หน้าค้นหา Shopee ตรงๆ:

```
https://shopee.co.th/search?keyword=${encodeURIComponent(keyword_th)}
```

พอแล้วสำหรับทดสอบว่า keyword ที่ AI แตกออกมาหาของเจอจริงไหม (งานข้อ 13 ในตาราง)

## ตอนได้ affiliate link แล้ว

1. **ทำมือ.** เอา URL (หน้าสินค้า หรือหน้า search ก็ได้) ไปวางในหน้าสร้างลิงก์ของ Shopee Affiliate แล้วเอาลิงก์ที่ได้มาใส่คอลัมน์ `deeplink` ไม่ต้องใช้ API
2. **Involve Asia.** Create Deeplink ในแดชบอร์ด หรือขอ API key แล้วยิง batch
3. แอปอ่านง่ายๆ: ถ้าแถวไหนมี `deeplink` ใช้อันนั้น ไม่มีก็ fallback ไป search URL

## เช็คไฟล์ไม่พังหลังแก้มือ

```bash
awk -F, 'NF!=13{print NR": "NF" cols"}' catalog/products.csv
```

ไม่ขึ้นอะไร = ผ่าน (ห้ามใส่ `,` ในช่องไหนก็ตาม ถ้าจำเป็นให้ครอบด้วย `"`)

## ผลเช็คคำค้นจริง (18 พ.ย. 2026)

ค้นครบทุกคำบน shopee.co.th แล้วทดสอบคำแทนอีก 19 คำ: ok 32 / fixed 11 / broad 6 / dup 1 (ไม่เหลือคำที่ผลปนจนใช้ไม่ได้)

กฎที่ได้จากการเช็ค ใช้ตอนให้ AI ออก keyword

1. Shopee จับได้ราว 2 ความหมายต่อคำค้น คำขยายตัวที่สามถูกเมิน (`โคมไฟตั้งพื้น ขาไม้` = `โคมไฟตั้งพื้น`)
2. ใส่วัสดุ/สี/ขนาดเป็นคำที่สามแล้วผลแย่ลง บางครั้งเหลือไม่ถึง 20 ชิ้น (`โคมไฟตั้งพื้น ไม้` = 15 ผล และไม่ใช่โคมไม้)
3. คำที่ชนของตามฤดูให้เลี่ยง `ต้นไม้ปลอม ต้นสูง` ได้ต้นคริสต์มาสเต็มหน้า ต้องระบุชนิดต้น (`ต้นมะกอกปลอม`)
4. คำทับศัพท์ที่ไทยไม่ใช้ค้นไม่เจอ `บีนแบ็ก` และ `เก้าอี้บีนแบค` คืนโซฟานั่งพื้นทั้งคู่ ใช้คำที่ร้านตั้งชื่อจริง
5. สไตล์ใช้เป็นคำขยายได้ผลดีกว่าวัสดุ (`โคมไฟเพดาน นอร์ดิก` ตรงกว่า `โคมไฟเพดาน ไม้`)
6. คำนำหน้าที่บอกหมวดช่วยกรองได้ดีกว่าคำขยายท้าย `ชุดผ้านวม` กรองผ้าห่มเย็นออกได้ ส่วน `ผ้านวม + สี` ไม่ได้ผล และ `โต๊ะพับญี่ปุ่น` ตรงกว่า `โต๊ะญี่ปุ่น เตี้ย ไม้`
7. ของกลุ่มช่าง/โรงรถให้ยืมคำจากงานอุตสาหกรรม `โคมไฟเพดาน โรงงาน` ได้โคมไฮเบย์ ส่วน `โรงรถ` อย่างเดียวได้แทรคไลท์ปน

แถว broad = คำค้นกว้างโดยตั้งใจ ให้กรองสไตล์/ขนาดในแอปเอง ไม่ใช่ที่คำค้น

## ประวัติการแก้

- 19 พ.ย. 2026: ห้องที่ 5 ในชุดทดสอบคือ **ห้องรก** ไม่ใช่ห้องรถ เปลี่ยน room_type จาก garage เป็น cluttered และเปลี่ยนสินค้าทั้ง 8 รายการจากของโรงรถ (ชั้นเหล็ก เพ็กบอร์ด รถเข็นช่าง) เป็นของจัดระเบียบบ้าน (กล่องเก็บของ ตู้ลิ้นชัก ตะกร้าสาน ราวแขวนเสื้อ) คำค้นใหม่ค้นจริงแล้วทั้ง 8 คำ

## ยังไม่ได้ทำ

- เช็คเฉพาะผลลัพธ์ 3 อันดับแรกของแต่ละคำ ไม่ได้ไล่ดูทั้งหน้า
- ไม่ได้เช็คว่าร้านไหนมีของจริง ส่งจริง หรือเรตติ้งเท่าไร
- `price_min/max` เป็นค่าประมาณจากราคาตลาดทั่วไป ไม่ได้ดึงจาก Shopee
- สไตล์ยังมีแค่ 7 ตัว ตารางวางไว้ 8–10 ค่อยเติมตอนทำแคตตาล็อกสไตล์เสร็จ
